# Astra

A static, dependency-free website (HTML + CSS + vanilla JS).

## Run locally
Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure
- `index.html` — page markup
- `css/style.css` — styles
- `js/main.js` — scripts
- `assets/` — images and icons

## Deploy
Import this repo into Vercel, Netlify, or enable GitHub Pages — no build step needed.
